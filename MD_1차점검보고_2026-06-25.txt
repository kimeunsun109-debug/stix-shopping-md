1. 플랫폼별 상위노출 구조 · 키워드 분석
================================================================================

【쿠팡 — 매출 1위】
  구조: [핵심키워드] + [형태] + [사이즈] + [용도/타겟]  (40자 내 직관)
  상위 노출 패턴 (2026.06 시장조사):
    · "보석십자수 캔버스형 DIY 키트 40x50 초보자"
    · "어린이 보석십자수 스티커 DIY 12종"
    · "해바라기/디즈니/명화 + 보석십자수 + 40x50"
  핵심 키워드: 보석십자수, DIY, 캔버스형, 40x50, 30x40, 키트, 초보자, 취미, 집콕
  가격대: 입문 12,900~19,000 / 일반 23,000~40,000 / 프리미엄 45,000~80,000
  ⚠ 자동 수집: 쿠팡 Access Denied → 시크릿모드 수동 검색 필요

【지마켓/옥션 — 매출 2위】
  구조: 키워드 최대 밀도 (60~80자), 유사어 반복 허용
  예: "보석십자수 DIY 키트 캔버스형 40x50 액자형 비즈십자수 취미 만들기 집콕"
  광고: ad.esmplus.com/cpp/management 노출보장형 → 판매 TOP + ROAS 추적
  그룹핑: 동일 도안·사이즈별 ESM 상품그룹 필수

【스마트스토어 — 매출 3위】
  구조: "스팃스 + 자연문장" (키워드 나열·괄호 남발 금지)
  예: "스팃스 보석십자수 DIY 키트 액자형 40x50 취미 만들기"
  태그: 10개, 중복·스팸형 금지

【11번가】
  구조: 쿠팡+지마켓 중간, "가성비·추천·9900" 키워드
  9900원샵: 25x25·30x40 입문 SKU 우선 추출

【카페24 자사몰】
  구조: 설득형 — "초보자도 쉽게 완성하는" 등 문제해결형

2. 내 사이트(스팃스/STIX) 분석 — 문제점
================================================================================

  [상품명]
  · 채널별 동일 상품명 사용 시 → 쿠팡(짧게)/지마켓(길게) 모두 손해
  · 스마트스토어에서 키워드 나열형 사용 시 네이버 SEO 패널티 위험
  · 11번가 가성비 키워드(9900, 추천) 미반영

  [매칭/노출 — 쿠팡]
  · Wing 매칭 오류 SKU 별도 추출 필요 (아이템위너·노출 분산)
  · 옵션명에 키워드 미반영 시 검색 손실

  [광고 — 지마켓/옥션]
  · 노출보장형 미등록 고판매 SKU 존재 가능
  · 상품그룹 미설정 → CTR·전환율 저하

  [썸네일]
  · 완성작 단일 컷·어두운 배경 → 클릭률 저하
  · 사이즈(40x50/30x40) 배지 미표시
  · 구성품·작업장면 컷 부재

  [상세페이지]
  · FAQ·사이즈표·구성품 정보 부족
  · alt 텍스트 SEO 미적용 (이미지안 텍스트.txt 기준)
  · 4분할 HTML 템플릿 미적용 SKU 다수

  [카테고리]
  · ESM/쿠팡 카테고리 오등록 시 필터 검색 누락

3. 상품명 개선안 (우선순위)
================================================================================

── 우선순위 A ──

  [판넬 액자형 40x50 공통]
  · 문제: 도안명만 있거나 키워드·용도·타겟 부족
  · 쿠팡: 보석십자수 캔버스 40x50 {도안명} DIY 키트 초보자
  · 지마켓: 보석십자수 DIY 키트 캔버스형 40x50 {도안명} 액자형 취미 만들기 집콕
  · 스마트스토어: 스팃스 보석십자수 DIY 키트 액자형 40x50 {도안명} 취미 만들기

  [판넬 액자형 30x40 공통]
  · 문제: 사이즈 표기 형식 불일치 (30X40 vs 30x40)
  · 쿠팡: 보석십자수 캔버스 30x40 {도안명} DIY 키트 집콕
  · 지마켓: 보석십자수 30x40 캔버스형 DIY {도안명} 액자형 취미세트

  [어린이 스티커형]
  · 문제: "어린이 보석십자수"만으로 스티커·종수 구분 없음
  · 쿠팡: 어린이 보석십자수 스티커 DIY 12종 만들기
  · 지마켓: 어린이 보석십자수 스티커 DIY 만들기 키트 12종 놀이세트

── 우선순위 B ──

  [해바라기/풍수 도안]
  · 개선: 인테리어·풍수 키워드 추가
  · 쿠팡: 해바라기 보석십자수 40x50 캔버스 DIY 인테리어

  [십자수 패키지]
  · 개선: 패키지·프랑스자수·자수세트 키워드
  · 지마켓: 십자수 패키지 {도안} DIY 프랑스자수 취미 자수세트

── 우선순위 C ──

  [11번가 9900원샵]
  · 25x25 입문 SKU → "보석십자수 25x25 DIY 키트 가성비 추천 초보자"

4. 썸네일 · 상세페이지 교체 목록
================================================================================

【썸네일 교체 — 우선순위 A】
  대상: 보석십자수 40x50·30x40 전체 라인
  문제: 완성작 단일·어두움·사이즈 미표시·클릭 유인 부족
  변경 구조:
    001_thumb : 완성작 + 사이즈 배지(40x50) + 밝은 배경
    002_main  : 완성작 고해상도 (흰/연베이지 배경)
    003_detail: 구성품 전체 (비즈·펜·트레이·도안)
    004_finish: 인테리어 연출 (거실/침실 액자)
  파일명: 보석십자수 {도안명}_001_thumb ~ _004_finish

【썸네일 — 우선순위 B】
  · 어린이: 캐릭터 클로즈업 + 아이 작업 장면
  · 십자수 패키지: 원단 질감 + 바늘실 구성

【상세페이지 — 우선순위 A】
  HTML 4분할 구조:
    1) 히어로: 완성작 + 한줄 카피 ("집콕 힐링, 3일 완성")
    2) 구성품: 4컷 + alt SEO
    3) 작업과정: 단계별 3~4장
    4) 사이즈표 + FAQ (초보자 난이도, 소요시간, 구성품 목록)
  템플릿: Desktop\쇼핑몰 프롬프트\자동화\상세페이지4분할-5개.html
  alt: Desktop\쇼핑몰 프롬프트\이미지안 텍스트.txt
